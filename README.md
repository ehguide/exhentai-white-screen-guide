# ExHentai 里站白屏解决指南：有权限却打不开 / 白屏 / 空白页（2026）
> **适用场景**：账号已经确认有里站（ExHentai）权限，但打开 `exhentai.org` 时一直**白屏、空白、加载不出来**。
> 如果你还不确定自己有没有里站权限，先看[里站权限自检](https://blog.exhentai.us.ci/2026/11/14/eh-permission/)，再回来对照本文排查。
---
## 先说结论
**白屏 90% 是网络链路问题，不是账号没权限。**
最常见的三种情况：出口 IP 质量差（共享节点被标记）、DNS 解析被污染、会话（Cookie）没有正确带上。按本文顺序排查，九成能自己解决。
---
## 一、30 秒快速自查：先分清「网络」还是「账号」
做下面 4 件事，把问题圈定在一个范围内：
| # | 动作 | 结果判断 |
|---|---|---|
| 1 | 打开表站 `https://e-hentai.org/` | 表站也打不开 → 多半是**网络/ DNS**，看第二节 |
| 2 | 换一个浏览器或无痕模式重新打开里站 | 好了 → **缓存 / 扩展冲突**，看第五节 |
| 3 | 换一个节点（美区 / 欧区优先） | 好了 → **节点 IP 质量差**，看第二节 |
| 4 | 用同一网络在浏览器登录表站 `home.php` | 登不进 → **会话/Cookie 问题**，看第四节 |
> 这一步不要跳过。很多人一白屏就怀疑账号被封，其实账号大概率没问题。
---
## 二、网络原因（最常见）
### 1. 出口 IP 质量差
**症状**：换了很多节点都不行；或偶尔能打开、多数时间白屏；或弹出人机验证后卡住。
**原因**：免费机场、试用节点、几十人共享的出口 IP 早就被站点标记为高风险，直接拒绝响应，表现就是白屏或验证死循环。
**解决**：
- 换**人少的付费节点**，地区优先 **美区 / 欧区**；
- 有条件的话用**住宅 / 家宽出口**，稳定性远好于机房 IP；
- 换节点后**彻底关闭浏览器或客户端再重开**，不要在旧会话里硬刷；
- 找到能用的节点后**固定下来**，不要每次换着用——里站对「同 IP 稳定登录」比较友好。
### 2. DNS 污染 / 安全 DNS 冲突
**症状**：域名解析不到正确地址、直连时白屏；或「网页能开但图片全不显示」。
**解决**：
- 大陆网络环境下，`exhentai.org` 的 DNS 解析可能被污染，**走代理是首选**；
- 使用 EHViewer 系客户端时，如果图片不显示，逐个关闭这三项再试（以绿E为例：**设置 → 高级**）：
  - `安全 DNS`
  - `内置 hosts`
  - `域名前置`
- 其中**「安全 DNS」最常见出问题**：它会让域名解析绕开代理，导致图片服务器连不上。注意这是备选手段，关掉后直连可能失效，能正常用就别动。

## 三、账号与权限确认
按下面顺序确认，**不要凭白屏就判断账号出事**：
1. 打开论坛 `forums.e-hentai.org`，确认登录的是**自己的正确账号**；
2. 回表站打开 `My Home`（我的主页），能打开说明账号状态正常；
3. **新注册的账号，里站权限不是即时生效的**：需要账号先保持正常使用，审核通过后才会解锁。旧教程常说的「10 天到一个月」是经验区间，不是保证；
4. **已捐赠的账号**：先在 My Home 核对累计等级，再刷新登录状态。**不要因为白屏就重复捐赠**；
5. 页面出现 `Sad Panda` 字样时，同样按「访问状态 + 网络」处理，它只是一个提示图，不代表具体原因。
---
## 四、Cookie / 会话问题
里站权限实际靠一组 Cookie 维持：`ipb_member_id`、`ipb_pass_hash`、`igneous`。白屏有可能是这组值缺失、失效或没被带上。
**处理步骤**：
1. 清理 `exhentai.org` 这一个域名的站点数据（**别顺手清空整个浏览器**）；
2. 重新登录论坛账号；
3. 登录后**实际打开一次** `https://exhentai.org/`——不打开这一步，`igneous` 不会生成；
4. 再回里站刷新测试。
**用客户端的话**，可以把浏览器里登录好的 Cookie 直接搬进应用（EHViewer 系支持 Cookie 登录，三个值分别填入）。
> ⚠️ **硬性安全线**：`ipb_pass_hash` 等同于你的密码。**任何第三方工具、客服、群友让你把 Cookie 三个值发过去，都等于把账号交出去。** 正常排查只需要你自己看，不需要发给任何人。
---
## 五、浏览器缓存 / 扩展冲突
**症状**：换个浏览器就好了；或只有某台设备白屏。
**解决**：
1. 无痕模式下打开里站测试；
2. 禁用广告拦截、脚本拦截类扩展（uBlock、AdGuard 等）后再试；
3. 只清理 `exhentai.org` 域名的缓存与 Cookie；
4. 浏览器内核太旧也会导致页面渲染失败，把 Chrome / Edge / WebView 更新到最新版。
---
## 六、站点临时故障
如果**表站、论坛、里站全部异常**，或者群里很多人同时白屏——那是站点本身在抽风，等恢复即可。
不要疯狂刷新：频繁请求只会让出口 IP 被临时限制，白屏没解决反而多一个问题。
---
## 常见误区
| 误区 | 事实 |
|---|---|
| 白屏 = 账号被封 | 多数是网络/会话问题，账号封禁会有明确提示 |
| 白屏 = 509 | 509 是**图片配额**用完，和白屏是两回事，处理方式不同 |
| 换个号试试 | 网络问题换号没用；先定位是网络还是账号 |
| 反复点验证 / 狂刷页面 | 请求越频繁，出口 IP 越容易被临时限制 |
---
## 一劳永逸：让里站稳定打开的配置
1. **固定一个干净的住宅 / 家宽出口**，不要频繁切换；
2. 浏览器保存会话，避免每次清 Cookie；
3. 客户端走 **Cookie 登录**，并在设置里把画廊站点切到 ExHentai；
4. 客户端选择参考：安卓 **绿E / 白E / 彩E**，iOS **EhPanda / FEhViewer**，跨平台 **JHenTai**；
5. 详细设置见：[E站客户端与常用设置](https://blog.exhentai.us.ci/2026/11/14/eh-settings/)。
